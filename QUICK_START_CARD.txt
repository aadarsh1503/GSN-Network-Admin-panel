┌──────────────────────────────────────────────────────────────┐
│  STEP 1: INSTALL NGROK (One Time Only)                      │
└──────────────────────────────────────────────────────────────┘

  1. Download: https://ngrok.com/download
  2. Extract ngrok.exe to: D:\GSN NETWORK\
  3. Sign up: https://dashboard.ngrok.com/signup
  4. Get token: https://dashboard.ngrok.com/get-started/your-authtoken
  5. Run in PowerShell:
     
     .\ngrok config add-authtoken YOUR_TOKEN_HERE

┌──────────────────────────────────────────────────────────────┐
│  STEP 2: START SERVERS (Every Time)                         │
└──────────────────────────────────────────────────────────────┘

  Terminal 1:
  ┌────────────────────────────────────────────────────────────┐
  │ cd server                                                  │
  │ npm start                                                  │
  └────────────────────────────────────────────────────────────┘

  Terminal 2:
  ┌────────────────────────────────────────────────────────────┐
  │ cd client                                                  │
  │ npm run dev                                                │
  └────────────────────────────────────────────────────────────┘

  Terminal 3:
  ┌────────────────────────────────────────────────────────────┐
  │ .\ngrok http 5173                                          │
  └────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│  STEP 3: SHARE THE LINK                                     │
└──────────────────────────────────────────────────────────────┘

  Look for this in Terminal 3:
  
  Forwarding    https://abc123.ngrok-free.app -> localhost:5173
                ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                COPY AND SHARE THIS URL!
