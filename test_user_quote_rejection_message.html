🔧 Implementation Details

Added Components:

  • getRejectedResponse(): Helper function to find rejected payment responses
  • Rejection Banner: Prominent red banner displayed at the top when payment is rejected
  • Company Info: Shows which company rejected the payment
  • Rejection Reason: Displays the company's notes for rejection
  • Rejection Date: Shows when the payment was rejected
  • Next Steps: Provides guidance on what the user should do next

⚠️ When Rejection Banner Appears

The rejection banner will be displayed when:

  • Payment Status: response.payment_status === 'rejected'
  • Company Notes: response.payment_company_notes contains rejection reason
  • Rejection Date: response.rejection_date is available (optional)
