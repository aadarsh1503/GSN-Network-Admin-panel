🔍 Root Cause Analysis

📊 Data Source Mismatch:

Transaction History: /api/enhanced-quotes/company-responses-with-payments
- Shows quotes with payment_status = 'verified'
- Quote #62 has verified payment ✅

My Quotes (OLD): /api/company-quotes/accepted-quotes
- Shows quotes with user_quote_status.status = 'accepted'
- Quote #62 might not have this status ❌

🎯 The Disconnect:

A quote can have verified payment without being marked as accepted in the user_quote_status table. This creates inconsistency between the two pages.

✅ Solution Implemented

🔧 Fix Applied:

Updated My Quotes to use the same data source as Transaction History

New My Quotes Logic:
1. Use /api/enhanced-quotes/company-responses-with-payments
2. Filter for quotes that have:
- user_response_status = 'accepted' OR
- payment_status = 'verified' OR
- payment_proof_url exists
3. Fallback to original API if enhanced API fails
