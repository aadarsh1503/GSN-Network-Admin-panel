## Template Variables to Replace

### Common Variables:
- `{{REGISTRATION_LINK}}` - User registration URL
- `{{COMPANY_REGISTRATION_LINK}}` - Company registration URL  
- `{{BUSINESS_REGISTRATION_LINK}}` - Business registration URL
- `{{WEBSITE_URL}}` - Main website URL
- `{{SUPPORT_EMAIL}}` - Support email address
- `{{VIP_SUPPORT_EMAIL}}` - VIP support email
- `{{COMPANY_NAME}}` - Target company name

### Personalization Variables:
- `{{USER_NAME}}` - Recipient's name
- `{{COMPANY_TITLE}}` - Recipient's job title
- `{{REFERRER_NAME}}` - Person who referred them
- `{{INVITATION_CODE}}` - Unique invitation code

## Implementation Notes

1. **Responsive Design**: All templates are mobile-responsive
2. **Brand Consistency**: Uses Gulf Star Network color scheme throughout
3. **Call-to-Action**: Clear, prominent buttons for registration
4. **Professional Tone**: Appropriate for B2B logistics industry
5. **Visual Hierarchy**: Proper use of headings, spacing, and colors
6. **Trust Indicators**: Testimonials and success stories included

## Usage Instructions

1. Replace all `{{VARIABLE}}` placeholders with actual values
2. Test email rendering across different email clients
3. Ensure all links are working and tracking is implemented
4. A/B test subject lines for optimal open rates
5. Personalize content based on recipient data when possible
