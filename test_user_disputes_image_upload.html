🔄 API Integration

Upload Flow:

  1. Create Dispute: POST to /api/disputes/create
  2. Upload Image: POST to /api/upload/image (FormData)
  3. Save Attachment: POST to /api/disputes/attachments
  4. Refresh Data: GET /api/disputes/my-disputes

File Validation:

  • ✅ Image files only (image/*)
  • ✅ Maximum 1MB per file
  • ✅ Maximum 1 file per dispute
  • ✅ Client-side validation before upload
