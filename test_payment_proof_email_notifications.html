📧 Payment Proof Email Notifications Test

📋 Test Overview:

When a user uploads payment proof, the system should send TWO emails:

  1. Company Email: Notification that payment proof has been uploaded
  2. User Email: Confirmation that their payment proof was successfully uploaded

🧪 How to Test

Step 1: Go to http://localhost:5173/business/quotes/83
Step 2: Find an accepted quote with bank details
Step 3: Click "Upload Payment Proof" button
Step 4: Upload an image file (JPEG, JPG, or PNG only)
Step 5: Fill in payment date and optional notes
Step 6: Submit the form
Expected Result: Two emails should be sent automatically

📧 Email #1: Company Notification

Recipient: Company email address

Subject: Payment Proof Uploaded - Quote #[ID] - GSN Network

Email Content Includes: • GSN Network branding • "Payment Proof Uploaded" header • Quote information (ID, customer name, amount) • Customer details (name, email) • Payment date and upload date • Customer notes (if provided) • Bank details used for payment • Action required section for company • Professional GSN Network footer

Purpose: Notify the company that a customer has uploaded payment proof and needs verification

📧 Email #2: User Confirmation

Recipient: User/Business user email address

Subject: Payment Proof Uploaded Successfully - Quote #[ID] - GSN Network

Email Content Includes: • GSN Network branding • "Payment Proof Uploaded Successfully" header • Upload confirmation details • Quote information (ID, company name, amount) • Payment date and upload date • File name of uploaded proof • User notes (if provided) • "What happens next" section • Important notes for user • Professional GSN Network footer

Purpose: Confirm to the user that their payment proof was successfully uploaded and explain next steps

⚠️ Important Notes

  • File Restrictions: Only image files (JPEG, JPG, PNG) are allowed
  • File Size: Maximum 5MB per file
  • Email Timing: Emails are sent immediately after successful upload
  • Error Handling: If email sending fails, the upload still succeeds but errors are logged
  • Database Updates: Payment proof is stored and verification status is set to "pending"

🔍 What to Check

  1. Upload Success: Payment proof uploads successfully
  2. Company Email: Company receives notification email
  3. User Email: User receives confirmation email
  4. Email Content: Both emails contain correct information
  5. Database Updates: Payment verification status is set to "pending"
  6. File Storage: File is uploaded to Cloudinary
  7. Console Logs: Check server console for email success/error messages

🚨 Troubleshooting

If emails are not sent:

  • Check server console for email errors
  • Verify email service configuration in .env file
  • Ensure EMAIL_HOST, EMAIL_USER, EMAIL_PASS are set correctly
  • Check if recipient email addresses exist in database
  • Verify quote and company data is properly retrieved

If upload fails:

  • Check file type restrictions (images only)
  • Verify file size is under 5MB
  • Ensure Cloudinary configuration is correct
  • Check database permissions for payment_proofs table

✅ Success Criteria

The test is successful when:

  • ✅ Payment proof uploads successfully
  • ✅ Company receives notification email with correct details
  • ✅ User receives confirmation email with correct details
  • ✅ Both emails have professional GSN Network branding
  • ✅ Database is updated with payment proof and verification status
  • ✅ File is stored in Cloudinary
  • ✅ Console shows successful email sending logs
