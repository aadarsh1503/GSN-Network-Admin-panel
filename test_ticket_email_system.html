📋 Email Notification Rules

  • Admin Tickets: Email sent to admin users only
  • Company Tickets: Email sent to target company AND admin users
  • Ticket Responses: Email sent to original ticket creator
  • Status Updates: Email sent to original ticket creator

🔍 How to Verify

  1. Check server console for email sending logs
  2. Check email_notifications table in database
  3. Verify actual email delivery (if SMTP is configured)
  4. Test with different user roles and company IDs
