🔧 Technical Implementation

State Management Added:

  • uploadingLogo - Tracks upload progress
  • logoFile - Stores selected file
  • logoPreview - Stores preview URL

Functions Added:

  • handleLogoSelect() - File selection and validation
  • handleLogoUpload() - Upload to server
  • removeLogo() - Remove existing logo

API Integration:

  • POST /api/upload/image - Upload image file
  • PUT /api/user/update-profile - Update profile with logo URL
  • Automatic profile refresh after upload

Validation Rules:

  • ✅ Image files only (image/*)
  • ✅ Maximum 5MB file size
  • ✅ Client-side validation before upload
  • ✅ Error handling for invalid files

🧪 Testing Instructions

How to Test Logo Upload:

  1. Navigate to http://localhost:5173/user/profile
  2. Click the "Edit Profile" button to enter edit mode
  3. Look for the camera icon on the avatar (bottom-right corner)
  4. Click the camera icon to open file selection
  5. Select an image file (JPG, PNG, GIF, etc.)
  6. Verify the image preview appears below the avatar
  7. Click the "Upload" button to upload the logo
  8. Verify the logo appears in the avatar circle
  9. Test the "Remove Logo" option if logo exists
  10. Test file validation with non-image files and large files

Expected Results:

  • ✅ Camera icon appears when editing
  • ✅ File selection opens on camera click
  • ✅ Image preview shows selected file
  • ✅ Upload progress is displayed
  • ✅ Logo appears in avatar after upload
  • ✅ Remove logo option works
  • ✅ File validation prevents invalid uploads
  • ✅ Toast notifications show success/error

🔍 Error Scenarios to Test
