🔧 Implementation Details

Enhanced Quote ID Detection:

Multiple Detection Methods:
1. notification.data.quote_id (primary)
2. Extract from message using regex
3. Extract from title using regex
4. Fallback to general quotes page

Button Text Logic:

Smart Button Text:
- With Quote ID: "View Quote #94"
- Without Quote ID: "View in Quotes"
- Other pages: "View in [PageName]"

⚠️ Quote ID Detection Sources

The system now checks multiple sources for quote ID:

  • Primary: notification.data.quote_id
  • Secondary: Regex pattern in message: /quote\s*#?(\d+)/i
  • Tertiary: Regex pattern in title: /quote\s*#?(\d+)/i
  • Fallback: General quotes page if no ID found
