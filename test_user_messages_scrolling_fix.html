🔧 UserMessages Scrolling Fix

Fixed the scrolling issue in UserMessages.jsx by taking reference from BusinessMessages.jsx implementation.

🐛 Issue Identified

The UserMessages component had incorrect height calculation causing scrolling problems:

❌ Before (Broken)

h-[calc(150vh-200px)]

Problem: 150vh is 150% of viewport height, making the container way too tall and causing scrolling issues.

✅ After (Fixed)

h-[calc(100vh-200px)]

Solution: 100vh is 100% of viewport height, providing proper container sizing.

📐 Height Calculation Explanation

  • 100vh = 100% of the viewport height
  • -200px = Accounts for header, padding, and other UI elements
  • calc(100vh-200px) = Dynamic height that adapts to screen size

Why 150vh was wrong:

  • 150vh = 150% of viewport height (way too tall)
  • Caused the container to extend beyond the visible area
  • Created unnecessary scrollbars and poor UX
  • Made the layout inconsistent with other message components
