🔧 Fix Admin Emails

This will update admin emails in the database to valid addresses for email notifications.

🔧 Quick Fix Instructions

Problem: Admin email "admin@gmail.com" doesn't exist, causing email failures.

Solution: Update admin emails to valid addresses.

Option 1: Database Update (Recommended)

UPDATE users SET email = 'root@khaleeji.app' WHERE id = 1 AND role = 'admin';

Option 2: Admin Panel

1. Login to admin panel
2. Go to Users management
3. Edit admin user ID 1
4. Change email to: root@khaleeji.app

After Fix:

1. Restart the server
2. Test ticket creation from business/user help page
3. Check server console for successful email logs
